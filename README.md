# Cardinal Maps

This is my latest attempt at a high-polish open source/open data maps app.

## Features

* Search for addresses, points of interest (POIs), administrative areas, and categories of places.
* Save POIs for easy access, and show them on the map.
* Get directions for driving, cycling and walking.

## Goals

Turn-by-turn navigation is planned with support for continuous local map matching for enhanced reroute performance. Transit routing is planned, including real-time transit. First class offline support is planned. End-to-end encrypted location sharing and social features for POI lists are planned.
