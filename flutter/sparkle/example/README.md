# sparkle_example

`sparkle_harness` as a Flutter app: a map of a tile server's tiles or local MBTiles and
GeoJSON files, drawn with Flutter GPU. Without arguments (as on Android) it shows the
tileset it was built with: `--dart-define=SPARKLE_TILES_URL=<TileJSON URL>`. See [the package README](../README.md) for how to run it.
